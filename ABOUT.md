# About project: Page Content to Markdown browser extension

Below is a a braindump via dictation for you to read and study.

This is a new project that we're creating. This is a fork of an existing repo on GitHub that contains browser extensions for both Firefox and Google Chrome. The original project has not been tested, reviewed, or optimized. It should be considered merely as a potential starting point. Any changes, minor or major, can be made without concerns.

The entire project will need to be reviewed and analyzed deeply. We'll see how good the foundation and starting point is, what adjustments need to be made before we start adding more features.

The goal of this project is to have a browser extension specifically for Firefox, but ideally also for Google Chrome, that lets a user convert an entire page to markdown format, which can be copied to a clipboard or saved as a file. Additionally and importantly, the extension should support converting certain elements and areas of content on the page to markdown format. So users can choose between the entire page or certain specific elements or sections of the page to convert to Markdown.

Additionally, we want to add native support for certain websites, specifically X, to have quick and easy predefined presets — for example, copy tweet to markdown, copy tweet and replies to markdown, copy X article to markdown, copy X article and replies to markdown, and so forth.

All this is just a brain dump to give you an idea of the project. We're starting with the fork rather than from scratch. We can make any and all changes we need. I expect you have lots of questions. When you do, ask them and I will answer. Don't assume. Use your ask user question function liberally.

Let's roll up our sleeves and dive in, which I imagine will start with a very deep and in-depth review of the goals I stated with the project, answering any and all questions you have initially, as well as a very thorough review of the original project — which will result in deciding how good or bad it is, what needs to be changed, and ultimately what the next steps are.
